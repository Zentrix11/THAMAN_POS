# THAMAN UI Design System

## Direction
Modern Premium Minimal — واجهة تجارية هادئة، واضحة، سريعة، بدون مؤثرات ثقيلة.

## Core colors
- Primary: #0F4B43
- Primary strong: #083A34
- Accent: #E46E2F
- Background: #F4F7F5
- Surface: #FFFFFF
- Text: #17211F
- Muted: #72807C
- Border: #E3E9E6

## Responsive breakpoints
- Mobile: less than 700px
- Tablet: 700px to 1079px
- Desktop: 1080px and above

## UX rules
- Cashier enters POS directly.
- Management sections are hidden by role, not merely visually disabled.
- Arabic uses RTL and English uses LTR.
- Back action is available on child workspaces.
- Sensitive financial content is hidden from non-financial roles.
