THAMAN POS V8.6 - مهم قبل التشغيل
=================================

هذه النسخة تحتوي ملفات Windows وAndroid وiOS وmacOS وWeb داخل المشروع.

Windows:
1) فك الضغط كاملًا.
2) افتح مجلد المشروع.
3) شغّل RUN_WINDOWS.bat.

أو يدويًا:
flutter pub get
flutter run -d windows

متطلبات Windows:
- Flutter مثبت ومضاف إلى PATH.
- Visual Studio 2022 مع Desktop development with C++.
- Windows 10/11 SDK.

Android: RUN_ANDROID.bat
iOS على Mac: RUN_IOS.sh
macOS على Mac: RUN_MACOS.sh
Web: RUN_WEB.bat

الجديد في V8.6:
- جرد محايد لموظف المخزن بدون عرض كمية النظام أو الفروقات.
- مراجعة واعتماد الفروقات للمالك/المدير فقط.
- رواتب + يوم قبض + صرف شهري يضاف للمصاريف والقيود.
- الرواتب مرئية فقط للمالك والمدير والمحاسب.
