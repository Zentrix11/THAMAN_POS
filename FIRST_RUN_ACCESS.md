# THAMAN POS V9.1 — First Run Access

There are no default management credentials on a fresh production install.

1. Launch THAMAN POS.
2. Enter the activation code generated in THAMAN Admin.
3. The server validates the subscription and registers this installation as a device.
4. After successful activation, the real store owner creates:
   - Owner name
   - Email
   - Password
   - Password confirmation
   - 4-digit management PIN
5. Later launches go to the normal access/login screen after a license heartbeat check.

If a device is unlinked, it can be activated again if the plan has a free slot. If it is blocked, activation is denied until THAMAN Admin unblocks it.
