# THAMAN POS V9.2.2

## Free-form SKU
- SKU is no longer converted to uppercase or forced into a specific pattern.
- Arabic, English, numbers, mixed case and symbols are accepted exactly as entered.
- SKU uniqueness remains required (case-insensitive) so search and scanning stay unambiguous.
- Applied to product management, inventory receiving, purchase/manual item creation, stock-count manual items, and outgoing manual inventory items.
- User-facing SKU fields now state that no fixed format is required.
