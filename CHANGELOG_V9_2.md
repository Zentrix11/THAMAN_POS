# THAMAN POS V9.2 — Offers, plans & subscription requests

Version: 0.29.0+34

- Added **العروض والباقات** to the management area.
- Displays live active plans/offers published from THAMAN Admin.
- Current plan provides **طلب تجديد الباقة**. Other plans provide **طلب هذه الباقة**.
- Requests are server-side and reach THAMAN Admin without changing the subscription automatically.
- Duplicate open requests for the same plan are prevented.
- Owner can submit requests; Manager/Accountant can view the catalog.
