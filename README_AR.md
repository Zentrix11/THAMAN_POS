# THAMAN POS V9.8 — Production Hardened

ثَمَن نظام نقاط بيع وإدارة متجر متعدد المنصات مبني بـ Flutter ومربوط بـ Supabase للاشتراكات والأجهزة والمزامنة.

الإصدار: **0.35.0+44**

## أهم الوحدات
- المبيعات والمشتريات والمخزون والعملاء والموردون والموظفون والتقارير.
- صلاحيات المالك/المدير/الموظفين.
- اشتراكات وباقات وأجهزة وتفعيل مركزي.
- مزامنة سحابية متعددة الأجهزة مع تخزين محلي مشفر.
- باقات مخصصة ومراسلة داخلية مرتبطة بطلب الباقة.
- تنبيهات انتهاء اشتراك فعلية محسوبة من وقت السيرفر + إشعارات نظام.
- استعادة دخول المالك بكلمة مرور مؤقتة من THAMAN Admin بدون إنشاء اشتراك جديد أو حذف بيانات.
- صفحة «مطور النظام» الخاصة بـ Zentrix.

## قبل الإطلاق
1. طبّق SQL 012 بعد 011.
2. شغّل `VERIFY_AFTER_012.sql` وتأكد أن كل `passed=true`.
3. شغّل `flutter clean && flutter pub get && flutter analyze && flutter test`.
4. ابنِ Release موقّعًا بالـkeystore الإنتاجي وجرب التفعيل/الفصل/التعليق/التجديد/الرسائل على جهازين حقيقيين.

راجع `FINAL_RELEASE_NOTES_AR.md` للتفاصيل.
